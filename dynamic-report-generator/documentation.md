# Dynamic Report Generator - Documentation

## Overview
The Dynamic Report Generator is a web application that allows you to create professional, visually engaging reports for Google PMax and Meta ads campaigns. The application features real-time data visualization, customizable themes, and templates specifically designed for digital marketing reports.

## Features

### 1. Dynamic Data Input
- Add custom analytics with label/value pairs
- Real-time updates as you enter data
- Organize metrics by categories (Traffic, PPC, SEO, Social)
- Pre-defined templates for Google PMax and Meta ads

### 2. Real-Time Visualization
- Charts and graphs that update dynamically as you input data
- Bar charts, line charts, and pie charts
- Data tables for campaign performance
- Custom chart data options

### 3. Customization Options
- Multiple theme options (Standard, Dark Mode, Light Mode, Corporate, Creative)
- Color customization for primary, secondary, and accent colors
- Layout options (Standard, Compact, Expanded, Grid)
- Logo upload and display controls

## How to Use

### Getting Started
1. Access the application at: http://3000-ikip6or7cs66yp2ofy75m-852cae94.manus.computer
2. The interface is divided into two main sections:
   - Left side: Data input and customization options
   - Right side: Live preview of your report

### Entering Data
1. Select the "Data Input" tab
2. Fill in the Report Title and Date Range
3. Enter values for the pre-populated metrics
4. Add new metrics using the "Add New Metric" section
5. Watch the live preview update in real-time

### Using Templates
1. Click the "Choose Template" button
2. Select from available templates:
   - Google PMax Basic
   - Meta Ads Performance
   - Comprehensive Digital Marketing
3. Click "Apply Template" to load the template metrics

### Customizing Appearance
1. Select the "Appearance" tab
2. Choose a theme or customize colors
3. Select a layout style
4. Upload your company logo
5. Toggle logo visibility as needed

### Generating Reports
1. Click "Preview Report" to see the full report in a new tab
2. Use "Generate Full Report" for the complete report with all visualizations
3. Click "Export Report" in the report view to print or save as PDF

### Customizing Charts
1. In the report view, find the "Chart Customization" section
2. Add custom channels to the distribution chart
3. Add custom campaigns to the campaign performance table
